INSTALACIÓN Y CONFIGURACIÓN
================================================================================

1. PREPARAR ORACLE DATABASE:
   - Instalar Oracle Database 19c
   - Crear usuario 'system' con contraseña '1234'
   - Verificar que el servicio esté ejecutándose en puerto 1521

2. EJECUTAR SCRIPT DE BASE DE DATOS:
   - Abrir Oracle SQL Developer
   - Conectar como system/1234@localhost:1521/orcl
   - Ejecutar el script: src/main/resources/oracle_schema.sql
   - Verificar que se crearon las tablas y secuencias

3. CONFIGURAR APLICACIÓN:
   - Clonar o descargar el proyecto
   - Verificar configuración en src/main/resources/application.properties
   - Ajustar credenciales Oracle si es necesario

4. COMPILAR Y EJECUTAR:
   - Abrir terminal en la carpeta del proyecto
   - Ejecutar: mvn clean compile
   - Ejecutar: mvn spring-boot:run
   - Esperar mensaje "Started TiendaApplication"

5. VERIFICAR INSTALACIÓN:
   - Abrir navegador en: http://localhost:80
   - Verificar estado: http://localhost:80/api/test/health
   - Probar diagnóstico: http://localhost:80/api/diagnostico/conexion-completa

MODELO DE DATOS
================================================================================

TABLAS PRINCIPALES:
- USUARIO: Usuarios del sistema con autenticación
- ROL: Roles de seguridad (ADMIN, USER, VENDEDOR)
- CATEGORIA: Clasificación de productos
- PRODUCTO: Catálogo con inventario y precios
- FACTURA: Cabecera de ventas realizadas
- VENTA: Detalle de productos vendidos

SECUENCIAS ORACLE:
- USUARIO_SEQ, ROL_SEQ, CATEGORIA_SEQ
- PRODUCTO_SEQ, FACTURA_SEQ, VENTA_SEQ

RELACIONES:
- Usuario → Rol (OneToMany)
- Categoria → Producto (OneToMany)
- Usuario → Factura (OneToMany)
- Factura → Venta (OneToMany)
- Producto → Venta (ManyToOne)

SOLUCIÓN DE PROBLEMAS COMUNES
================================================================================

PROBLEMA: Error de conexión Oracle
SOLUCIÓN: 
- Verificar que Oracle esté ejecutándose
- Comprobar credenciales en application.properties
- Ejecutar: http://localhost:80/api/reparacion/estado-aplicacion

PROBLEMA: Error 403 Forbidden (SOLUCIONADO)
SOLUCIÓN:
- ✅ RESUELTO: Métodos privados cambiados a públicos en CrudMaestroController
- Todos los endpoints /api/** ahora son accesibles públicamente
- Verificar que la URL sea correcta
- Para funciones administrativas, iniciar sesión primero

PROBLEMA: Errores de tipos de datos
SOLUCIÓN:
- Ejecutar: http://localhost:80/api/reparacion/corregir-tipos
- O ejecutar manualmente: src/main/resources/limpiar_oracle.sql

PROBLEMA: Datos de prueba duplicados
SOLUCIÓN:
- Ejecutar: http://localhost:80/api/limpieza/limpiar-datos-prueba
- Verificar estado: http://localhost:80/api/limpieza/verificar-estado

PROBLEMA: Rendimiento lento
SOLUCIÓN:
- Verificar: http://localhost:80/api/diagnostico/rendimiento
- Revisar configuración HikariCP en application.properties
- Verificar memoria disponible del sistema

PROBLEMA: Aplicación no inicia
SOLUCIÓN:
- Verificar que Oracle esté ejecutándose
- Comprobar que el puerto 80 esté disponible
- Revisar logs de Spring Boot para errores específicos
- Verificar que las tablas existan en Oracle
